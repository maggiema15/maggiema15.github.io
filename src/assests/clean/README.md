# Cleaned artwork copies

These files are non-destructive, pixel-preserving trims of transparent padding
from the original PNGs one directory up. They exist so CSS dimensions describe
the visible object instead of an oversized transparent canvas.

| Clean file | Source | Why it exists |
| --- | --- | --- |
| `top-rack-tight.png` | `top rack.png` | Tight shelf bounds |
| `bottom-rack-tight.png` | `bottom rack.png` | Tight shelf bounds |
| `table-v2-tight.png` | `table v2.png` | Removes the large transparent top area |
| `window-v3-tight.png` | `window v3.png` | Tight window bounds |
| `guitar-tight.png` | `guitar.png` | Tight guitar bounds |
| `wall-plant-tight.png` | `wall plant.png` | Tight vine bounds |
| `pot-plant-tight.png` | `pot plant.png` | Tight plant bounds |
| `light-on-top-tight.png` | `Light on top.png` | Removes unused transparent border |

The album covers and contact vinyls were left pixel-for-pixel unchanged. The
small sparkle visible on two album covers may be intentional artwork, so it was
not removed automatically.
